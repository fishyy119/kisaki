# Kisaki Extension Tooling v0.0.11

## Breaking Changes

- Changed all extension tooling packages to publish ESM-only builds; CommonJS artifacts are no longer shipped
- Required extension entry files to use `.mjs`; the manifest no longer accepts `.cjs` entries
- Changed registry manifests to plain-text package `summary` with optional `description`, and release changelogs to `text` / `url` fields, removing `releasePage` and localized document sets
- Changed `kisx registry add-release` to accept `--changelog <text>` and `--changelog-url <url>`, removing `--release-page`, `--changelogs`, and `--default-locale`
- Removed the `card` and `cardForeground` webview theme tokens and their SDK CSS variables

## Migration Notes

- Required extensions with `.cjs` entry files to migrate to `.mjs` and import tooling packages as ESM
- Required existing registry manifests to move localized descriptions and changelogs to plain-text `summary` / `description` and `changelog.text` / `changelog.url`
- Required publish workflows generated by earlier scaffolds to pass release notes via `--changelog` / `--changelog-url` instead of maintaining `<locale>.md` changelog directories
- Required webview UIs to replace card tokens such as `bg-card` with existing tokens such as `bg-surface` or `bg-input`

## Improvements

- Improved `kisx pack` to produce byte-for-byte reproducible `.kisx` archives
- Improved visual consistency of extension UI components, including checkbox, switch, tabs, and field separator
- Improved scaffold templates to target ESLint 10, TypeScript 6.0, and current toolchain versions with unified lint cache settings
