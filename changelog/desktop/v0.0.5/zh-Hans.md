# Kisaki v0.0.5

## 重点

- 新增任务中心，统一追踪扫描、导入、扩展和更新任务的进度与历史
- 改进自动化系统，支持手动、启动时和 Cron 触发命令，并查看运行结果
- 新增重复实体合并流程，支持把游戏、人物、公司、角色、收藏和标签合并到目标实体

## 破坏性变更

- 调整扩展兼容性检查为 Extension API 版本，旧的 Kisaki 引擎兼容声明不再作为兼容依据
- 移除旧扩展设置面板贡献方式，扩展需要迁移到 Webview UI

## 新功能

- 新增任务中心搜索、分类筛选、活动任务控制和已完成记录清理
- 新增扩展任务运行 API，支持扩展把长流程接入任务中心
- 新增扩展 Webview UI 能力，支持更大对话框、主题外观桥接和任务结果展示
- 新增库图谱导入能力，支持扩展按关系批量写入媒体、人物、公司、角色和附件
- 新增 Bangumi Webview 设置页，集中管理账户、同步、导入、自动化和维护操作
- 支持一键添加 Kisaki 官方扩展仓库

## 修复

- 修复全局滚动条样式和应用字体加载异常
- 修复删除确认弹窗关闭后可能保留上一次状态的问题
- 修复提醒弹窗操作语义和部分弹层层级不正确的问题
- 修复库图谱导入时外部 ID 冲突可能跨节点误判的问题
- 修复扩展卡片作者信息间距不一致的问题
- 修复自动化运行历史序号显示不正确的问题

## 改进

- 改进扫描、刮削、导入、扩展安装、仓库刷新和应用更新的进度展示
- 改进扩展安装与更新流程，统一版本计划、签名风险、更新日志和应用结果展示
- 改进 Bangumi 集成导入与同步预览，使运行前的选项和诊断更清晰
- 调整游戏启动与停止流程，增加状态通知
- 调整刮削提供者 ID 按媒体类型隔离，降低不同媒体来源互相冲突的风险
- 优化扩展 Webview 字体加载，改用随应用打包的字体资源
