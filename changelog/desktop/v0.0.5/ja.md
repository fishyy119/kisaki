# Kisaki v0.0.5

## ハイライト

- 追加 タスクセンターでスキャン、インポート、拡張機能、更新タスクの進行状況と履歴をまとめて追跡
- 改善 自動化で手動、起動時、Cron によるコマンド実行と実行結果の確認に対応
- 追加 ゲーム、人物、会社、キャラクター、コレクション、タグの重複エンティティ統合フロー

## 破壊的変更

- 変更 拡張機能の互換性チェックを Kisaki エンジンバージョンではなく Extension API バージョン基準にしました
- 削除 旧来の拡張機能設定パネルコントリビューションを廃止し、Webview UI への移行を必須にしました

## 新機能

- 追加 タスクセンターの検索、カテゴリーフィルター、実行中タスクの操作、完了記録の整理
- 追加 拡張機能タスク実行 API により、拡張機能の長い処理をタスクセンターに表示可能にしました
- 追加 拡張機能 Webview UI 機能により、大きなダイアログ、テーマ外観ブリッジ、タスク結果表示に対応
- 追加 ライブラリグラフインポートにより、拡張機能が関連するメディア、人物、会社、キャラクター、添付ファイルを一括書き込み可能にしました
- 追加 Bangumi Webview 設定ページで、アカウント、同期、インポート、自動化、メンテナンスをまとめて管理可能にしました
- 対応 Kisaki 公式拡張機能リポジトリをワンクリックで追加できるようにしました

## 修正

- 修正 グローバルスクロールバーのスタイルとアプリフォント読み込みの問題
- 修正 削除確認ダイアログを閉じた後に以前の状態が残ることがある問題
- 修正 アラートダイアログのアクション意味付けと一部オーバーレイの表示階層
- 修正 ライブラリグラフインポートで外部 ID の競合が無関係なノード間で検出されることがある問題
- 修正 拡張機能カードの作者表示の余白が不揃いになる問題
- 修正 自動化の実行履歴で連番が正しく表示されない問題

## 改善

- 改善 スキャン、スクレイピング、インポート、拡張機能インストール、リポジトリ更新、アプリ更新の進行状況表示
- 改善 拡張機能のインストールと更新で、リリース計画、署名リスク、変更履歴、適用結果を統一
- 改善 Bangumi のインポートと同期プレビューで、実行前のオプションと診断を分かりやすくしました
- 変更 ゲームの起動と停止フローで状態通知を表示するようにしました
- 変更 スクレイパープロバイダー ID をメディア種別ごとに分離し、メディアソース間の競合リスクを低減
- 最適化 拡張機能 Webview のフォント読み込みを、アプリに同梱されたフォントリソースから配信する方式にしました
