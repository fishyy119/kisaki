# MangaDex Extension

Built-in MangaDex integration for Kisaki.

- Comic scraper provider with multilingual titles, canonical tags, per-volume
  cover art, author/artist credits, and related entries. MangaDex entries also
  hand over MAL and AniList ids when the source states them.
- Person scraper provider for author and artist entities.
- Reading integration: sign in with a MangaDex personal client (the official
  channel for personal tools — client id, client secret, username, and
  password stay in the local secret store), import reading statuses and
  ratings into the library, and push local status and score changes back.
