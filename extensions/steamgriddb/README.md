# SteamGridDB Extension

Built-in SteamGridDB artwork scraper for Kisaki.

- Game artwork provider backed by the community art database: 600×900 grid
  covers, hero backdrops, transparent logos, and icons — the only built-in
  source for game logo and icon slots.
- Requires a free personal API key. Entries carrying a Steam app id resolve
  directly through the Steam id bridge; anything else resolves by name search.
